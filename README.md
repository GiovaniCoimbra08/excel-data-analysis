# Análise de Pedidos por Estado - Excel

Projeto simples utilizando:
- Excel
- Tabela Dinâmica
- Gráfico de Colunas

## Objetivo
Analisar a quantidade de pedidos por estado utilizando dados de e-commerce.

## O que foi utilizado
- Tabela dinâmica
- Contagem de pedidos
- Ordenação de dados
- Gráfico de colunas

## Resultado
Foi possível identificar os estados com maior número de pedidos.
